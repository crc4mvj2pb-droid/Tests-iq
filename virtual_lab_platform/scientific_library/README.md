# Virtual Lab Scientific Library

This folder is the beginning of the scientific-model and reference-data library.

Each entry must separate:
- bibliographic provenance and source URL/DOI,
- original model author and license,
- assumptions and units,
- reference input/output data,
- verification tests,
- validation status and known limitations.

Do not mark an entry as experimentally validated merely because its code runs. Never store personal, confidential, unpublished or licensed data without permission.
