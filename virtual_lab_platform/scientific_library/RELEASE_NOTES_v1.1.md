# Virtual Lab Platform v1.1

## Virtual laboratory designer
- Added a catalogue-driven lab workbench with selectable disciplines, workflows, components/samples, equipment and protocol steps.
- Added equipment metadata for capabilities and illustrative capacities/ranges.
- Added pre-run validation for missing components/equipment, invalid steps, discipline mismatches, transfer capacity and vessel capacity.
- Added an ideal solution-dilution calculator and a Michaelis–Menten enzyme-assay demo.
- Added L0 workflow templates for microscopy, PCR, environmental screening and materials heating. These are clearly marked workflow-only until domain solvers are connected.
- Added downloadable JSON experiment dossiers with the configuration, validation report, output, assumptions and limitations.

## Limitations
This release is not a 3D environment or digital twin of commercial instruments. Catalog capacities are illustrative. Only explicitly implemented calculators return numeric results. No biological, clinical, chemical safety, environmental impact or engineering result is validated for real-world decisions.
