# Virtual Lab Platform v0.9
- Local SBML/XML intake with metadata extraction and SHA-256 provenance.
- Local CSV dataset intake with structure checks, source metadata and SHA-256 provenance.
- Local import panel and imported-assets registry.
- Imported models are stored, not executed; no scientific validation is implied.
Run `sh launch_macos_linux.sh` on macOS/Linux or `launch_windows.bat` on Windows. Requires Python 3.10+.
