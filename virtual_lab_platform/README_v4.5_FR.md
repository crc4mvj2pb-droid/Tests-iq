# Virtual Lab Platform v4.5

Sauvegarde fiable :
- un format de dossier unique, avec versions et empreinte complète ;
- une vérification à trois niveaux ;
- un rejeu qui compare ses résultats à l'original ;
- une migration des anciennes bases avec sauvegarde automatique ;
- un export et un import sans perte, qui refusent les fichiers altérés ;
- l'import d'une paillasse depuis un fichier.
