# Release notes — v3.6

- Nouveau module serveur de stœchiométrie avec calcul d'avancement, réactif limitant, quantités restantes et produits théoriques.
- Analyse des formules chimiques avec prise en charge des groupes entre parenthèses et de leurs indices entiers.
- Contrôle atomique côté serveur : une équation non équilibrée est refusée lorsque toutes les formules sont disponibles.
- Intégration de l'interface de réactions à l'API : aucune quantité de paillasse n'est modifiée si le calcul est refusé.
- Ajout de tests sur l'équation équilibrée, les réactifs limitants, les formules, les entrées invalides et l'intégration UI/API.
