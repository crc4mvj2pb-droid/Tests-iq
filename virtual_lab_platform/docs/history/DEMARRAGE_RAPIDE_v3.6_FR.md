# Démarrage rapide — v3.6

1. Extraire l'archive ZIP.
2. Ouvrir un terminal dans le dossier `virtual_lab_platform_v3_6`.
3. Lancer `python3 app.py` sur macOS/Linux ou `python app.py` sur Windows.
4. Ouvrir http://127.0.0.1:8765.
5. Dans la paillasse, choisir une réaction dans le panneau de stœchiométrie.
6. Cliquer sur « Ajouter les réactifs à la zone » et vérifier les quantités en mol.
7. Cliquer sur « Calculer l'avancement stœchiométrique ». Le serveur vérifie les formules avant de modifier les quantités.
8. Examiner le réactif limitant, les produits théoriques et le dossier JSON détaillé.

Attention : bilan idéal seulement, sans cinétique, équilibre, rendement ni validation de sécurité.
