# Démarrage rapide — Virtual Lab Platform v3.9

1. Décompressez `virtual_lab_platform_v3_9.zip`.
2. Ouvrez un terminal dans le dossier extrait.
3. Lancez `python app.py` (Windows : vous pouvez aussi lancer `launch_windows.bat`).
4. Ouvrez `http://127.0.0.1:8765` dans votre navigateur.

## Navigation clavier

- Utilisez Tab pour atteindre les catégories et les éléments de la paillasse.
- Activez une catégorie avec Entrée ou Espace.
- Sur un élément de la paillasse, Entrée ou Espace le sélectionne; les boutons intégrés restent des commandes distinctes.
- Le champ de recherche filtre la bibliothèque pendant la saisie.

## À savoir

Cette plateforme est un prototype local. Les modèles et instruments sont pédagogiques; vérifiez toujours les hypothèses et les limites affichées.
