# Virtual Lab Platform v4.3

Paillasse fiable : un seul format de sauvegarde et d'export, une restauration qui nettoie et signale les références invalides, une suppression sans fil orphelin, des valeurs invalides signalées plutôt que remplacées par 0, et un marquage des composants non calculés. Voir `RELEASE_NOTES_v4.3_FR.md` et `VALIDATION_MATRIX_v4.3.md`.

Lancer : `python app.py`, puis http://127.0.0.1:8765. Vérifier : `python scripts/run_validation.py`.
