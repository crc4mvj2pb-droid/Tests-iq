# Virtual Lab Platform v3.4

Version de stabilisation de l’interface issue de la v3.3.

## Lancement sur macOS / Linux
Dans le Terminal, depuis le dossier extrait :
```bash
sh launch_macos_linux.sh
```
Puis ouvrir http://127.0.0.1:8765.

## Lancement sur Windows
Lancer `launch_windows.bat`, ou utiliser `python app.py` dans le dossier du projet.

## Changements
- Correction de règles CSS en double qui réduisaient les dimensions des catalogues.
- Cartes de catalogue plus grandes, textes mieux gérés et mise en page responsive.
- Tests navigateur des interactions principales et de la catégorie Électricité & électronique.
