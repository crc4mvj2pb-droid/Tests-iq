# Virtual Lab Platform v3.3

Version de présentation basée sur la v3.2.

### Démarrage sur macOS / Linux
```bash
cd chemin/vers/virtual_lab_platform_v3_3
python3 app.py
```
Puis ouvrir http://127.0.0.1:8765.

### Démarrage sur Windows
Lancer `launch_windows.bat` ou utiliser un terminal dans le dossier :
```powershell
python app.py
```

### Modifications de cette version
- Bibliothèque scientifique élargie, cartes plus grandes et plus lisibles.
- Ajustements responsives pour limiter les superpositions et les débordements.
- Repères textuels professionnels à la place des emojis dans les catalogues.
- Les fonctionnalités et limites scientifiques héritées de la v3.2 sont conservées.
