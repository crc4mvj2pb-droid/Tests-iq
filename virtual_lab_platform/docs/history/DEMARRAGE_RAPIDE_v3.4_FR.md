# Démarrage rapide — Virtual Lab Platform v3.4

## macOS
1. Décompresse `virtual_lab_platform_v3_4.zip`.
2. Ouvre Terminal dans le dossier `virtual_lab_platform_v3_4`.
3. Lance :

```bash
sh launch_macos_linux.sh
```

4. Ouvre http://127.0.0.1:8765 dans Safari ou Chrome.
5. Pour arrêter le serveur, reviens au Terminal et fais `Ctrl+C`.

Python 3.10 ou plus récent est requis.

## Windows
Double-clique sur `launch_windows.bat`, ou ouvre un terminal dans le dossier et exécute `python app.py`.

## Vérification de l’interface
- Sélectionne une catégorie dans la bibliothèque.
- Utilise la recherche pour filtrer les objets.
- Clique sur « Ajouter » ou glisse une carte sur la paillasse.
- Sélectionne un objet pour modifier ses paramètres dans le panneau de propriétés.
- Supprime un objet depuis sa carte ou le panneau de propriétés.

La catégorie « Électricité & électronique » contient des composants et instruments. Leur présence au catalogue ne signifie pas que tous sont pris en charge par le solveur. Les modèles exécutables et leurs limites restent indiqués dans le projet.
