# Démarrage rapide — Virtual Lab Platform v3.2

1. Décompresse l'archive dans un dossier.
2. Lance `launch_windows.bat` sur Windows ou `python3 app.py` sur macOS/Linux.
3. Ouvre l'adresse locale affichée dans le terminal.
4. Parcours le catalogue par discipline : tu trouveras maintenant 18 disciplines, 58 composants, 70 équipements et 42 workflows.
5. Vérifie toujours le niveau du modèle. `L0` = fiche de planification sans calcul scientifique. `L1` = démonstration simplifiée avec contrôles mathématiques de base.
6. Pour une expérience calculable, sélectionne un modèle marqué `implemented_demo` ou un workflow dont le calculateur est explicitement indiqué.

Les paramètres fournis à titre d'exemple ne sont pas des données de référence. Les nouveaux instruments ne sont pas automatiquement reliés à un simulateur physique.
