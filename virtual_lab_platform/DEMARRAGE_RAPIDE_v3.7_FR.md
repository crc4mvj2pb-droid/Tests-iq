# Démarrage rapide — Virtual Lab Platform v3.7

1. Décompresser `virtual_lab_platform_v3_7.zip`.
2. Ouvrir un terminal dans le dossier `virtual_lab_platform_v3_7`.
3. Windows : `python app.py` ; macOS/Linux : `python3 app.py`.
4. Ouvrir http://127.0.0.1:8765 dans le navigateur.
5. Dans **Instruments virtuels et incertitudes**, choisir un instrument, saisir une valeur théorique et cliquer sur **Simuler une mesure**.
6. Tester un biais instrumental et une correction d’offset. Avec la même graine aléatoire, la simulation est reproductible.
7. Consulter le budget détaillé pour voir les contributions à l’incertitude-type et l’intervalle élargi `k=2`.

**À retenir :** les résultats sont simulés et pédagogiques, pas expérimentaux. Les valeurs d’incertitude du catalogue ne sont pas des spécifications de fabricants.
