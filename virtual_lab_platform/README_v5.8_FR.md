# Virtual Lab Platform v5.8

Expériences multi-modèles :
- des modèles enchaînés par des liaisons dont les unités sont converties et vérifiées ;
- les incompatibilités sont refusées avec un code (dimensions, ordre de réaction, étape ou sortie inconnue) ;
- les écarts d'échelle de temps sont signalés ;
- chaque étape conserve ses entrées, conversions, sorties, hypothèses, provenance et maturité ;
- la maturité de la chaîne est celle de son étape la plus faible ;
- sauvegarde en dossier et rejeu.
